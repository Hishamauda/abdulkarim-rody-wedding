# عبد الكريم & رودي — دعوة زفاف إلكترونية ملكية

**الرابط (بعد النشر):** https://hishamauda.github.io/abdulkarim-rody-wedding/

دعوة زفاف ثابتة (Static) بلا خادم وبلا مكتبات خارجية، جاهزة للنشر على GitHub Pages.
الاتجاه الفني: **Royal Ivory — Champagne Gold — Timeless Romance**.

## المشاهد
1. **فتح الدعوة:** ظرف ملكي مغلق بختم شمع ذهبي يحمل الحرفين «ع» و«ر». عند الضغط ينكسر الختم، وينفتح الغطاء ثلاثي الأبعاد، وتخرج البطاقة.
2. **الكشف الكبير:** يُكتب الاسمان بالذهب من اليمين إلى اليسار، ثم يمرّ عليهما وميض ضوء ذهبي، ويليهما التاريخ وعبارة «ليلةٌ من العمر... تكتمل بوجودكم.»
3. **نص الدعوة الرسمي:** يبدأ بالبسملة، ويضم أسماء الوالدين وكُناهما.
4. **مكان الحفل:** قوس قصر يُرسم أمام الضيف، وزر خرائط Google، وزر حفظ الموعد في تقويم Google أو بملف `.ics` لأجهزة iPhone وOutlook.
5. **العد التنازلي:** حيّ حتى الساعة 4:00 مساءً بتوقيت غزة، ثم يتحول إلى «حان موعد الفرح... أهلاً بكم في ليلتنا.»
6. **برنامج الحفل:** خط ذهبي عمودي يضيء أثناء التمرير.
7. **بكل محبة وتقدير:** لوحة هادئة دون أي أيقونات منع.
8. **أهدونا الحب غيباً بالدعاء:** تُكتب العبارة بكشف بطيء بين غصنين ذهبيين.
9. **الختام:** حلقة ذهبية وشرارات ضوء مرة واحدة، ثم «ننتظركم بكل محبة».

**القائمة السفلية الزجاجية:** الرئيسية، والقاعة، والبرنامج، والمشاركة (Web Share API، ومع غيابه يُنسخ الرابط)، والموسيقى.

## تعديل البيانات
كل النصوص والبيانات في ملف واحد هو `assets/js/config.js`. بعد أي تعديل شغّلوا:
```bash
node tools/sync.mjs
```
يحدّث هذا الأمر وسوم معاينة الرابط (Open Graph) والنصوص الثابتة في `index.html` وملف التقويم `assets/wedding.ics`.
لتحديث صورة المعاينة `assets/img/og-image.jpg` وأيقونة الهاتف، يلزم تثبيت Playwright ثم:
```bash
node tools/og.mjs
```

## الهيكل
```
index.html                 الصفحة (كل المشاهد)
assets/css/tokens.css      رموز التصميم (مولَّدة من design/tokens.json)
assets/css/main.css        التنسيق والحركة
assets/js/config.js        ⟵ كل بيانات الدعوة
assets/js/app.js           التفاعل: الظرف، العد التنازلي، التقويم، المشاركة، الكشف عند التمرير
assets/js/music.js         موسيقى هادئة أصلية تُولَّد في المتصفح (Web Audio)، ولا تعمل قبل تفاعل الضيف
assets/fonts/              Aref Ruqaa وAmiri بصيغة WOFF2 مقتطعة + تراخيص SIL OFL
assets/img/                الختم، والغصن، والفاصل، وزخرفة الزوايا، وصورة المعاينة، والأيقونات (رسوم أصلية)
assets/wedding.ics         ملف التقويم
design/                    tokens.json + DESIGN.md (الاتجاه الفني ونظام التصميم)
tools/                     sync.mjs · og.mjs · qa.mjs · make_assets.py · subset_fonts.sh
qa/                        تقرير الفحص وصور الشاشات
```

## ملاحظات
- **الخط الديواني:** لا يوجد خط ديواني مفتوح الترخيص. استُخدم Aref Ruqaa للأسماء بعد اختبار البدائل التي أفسدت الحروف (التفاصيل في `design/DESIGN.md`).
- **الموقع على الخريطة:** رابط بحث نصي عن «قاعة روفان، بجوار برج الشفاء، غزة» دون أي إحداثيات مخترعة.
- **نهاية حدث التقويم:** 9:00 مساءً، وهي نهاية تقريبية لأن التقويم يتطلب وقت نهاية. يمكن تعديلها في `config.js` (`event.endTime`).
- **الحقوق:** لا يحتوي الموقع على أي ملف من المستودع المرجعي. الخطوط برخصة OFL، وكل الرسوم والموسيقى أصلية.
